# Today in Discord.
 The perfect [server stats bot](https://todayindiscord.xyz). We offer more data than any other statistics bot out there.

https://todayindiscord.xyz

## How to install?
Add the bot to your server using the [invite link](https://discord.com/oauth2/authorize?client_id=1017659005818126358)

Ensure the bot has the permissions necessary to track data.

And sit back! Today in Discord will now watch your server and give you interesting insights into your community.

Run either the /graph or /leaderboard command to see your data or run the /summaries generate command to see an AI overview of everything.
